# DEC-021 — Граница продукта и контракт репозитория

## Решение

madarch — самостоятельный движок и CLI; продуктовый репозиторий описывается версионируемым контрактом. Движок не включает навыки, формы и типы; набор shady2k-skills владеет формами и проверками. Жизненный цикл репозитория продукта реализует сам madarch.
