# DEC-023 — Границы хранения данных

## Решение

Для каждого класса данных определяется один источник истины: авторские документы — в Git продукта, код — в собственных репозиториях, импортированные факты — в системе-источнике с записью в журнале, производные индексы перестраиваются локально. Эти классы не становятся независимо редактируемыми копиями друг друга.
