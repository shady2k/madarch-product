# DEC-024 — Движок не содержит данных конкретного продукта

## Решение

Владелец потребовал, чтобы в движке не было захардкожено содержимое продукта. Сведения о типах, стадиях и содержании предоставляет продуктовый репозиторий. Это правило принято вместе с включением собственной вики madarch в текущую веху; отдельной записью решения в исходных документах движка не оформлено.

## Основание

Утверждение владельца отражено в уставе текущей вехи standalone и в задаче собственной продуктовой вики.
