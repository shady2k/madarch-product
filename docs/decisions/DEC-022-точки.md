# DEC-022 — Точки расширения архитектуры

## Решение

Продуктовый репозиторий — единственный источник авторских данных. Движок знает механизм, а типы сущностей и формы задаются данными продукта. Будущие агенты и внешние платформы подключаются через опубликованный контракт, не встраивая управление исполнением в движок.
