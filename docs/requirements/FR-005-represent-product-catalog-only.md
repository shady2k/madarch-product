# FR-005 — Репозиторий продукта представлен только сущностями каталога

Serves: UC-005
Verified by: inspection

## Requirement

Репозиторий продукта представлен в графе только сущностями каталога из его манифестов и настроек. Экземпляры «Репозиторий», «Папка» и «Файл» появляются в графе только из привязанных репозиториев кода.

## Sources

- S-003 L13-13 "Репозиторий продукта — это его манифесты и настройки. Именно из этих манифестов в граф попадают сущности каталога."
- S-003 L15-15 "Репозиторий продукта тоже попадает в граф, его сущности там создаются"
- S-003 L16-16 "Только его сущности"
