# FR-006 — Единые правила чтения репозиториев

Serves: UC-005
Verified by: test

## Requirement

При заполнении графа madarch читает все репозитории по одним правилам. Код самого madarch, привязанный к продукту как репозиторий кода, описывается в графе так же, как сторонний код.

## Sources

- S-003 L9-9 "Наш движок не должен содержать никаких данных … Никакого хардкода."
- S-003 L18-18 "Собственный репозиторий продукта заполняется через тот же шлюз, что и подключённые — верно. Действительно наш репозиторий madarch будет описываться точно также как и сторонние."
