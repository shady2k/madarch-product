# FR-004 — При старте сервера каталог записывается в граф

Serves: UC-005
Verified by: test

## Requirement

При старте сервера madarch проверяет манифесты продукта. Если проверка проходит, виды, поля, связи и процессы из манифестов записываются в граф как сущности каталога без участия агента. Если проверка не проходит, сервер не запускается.
