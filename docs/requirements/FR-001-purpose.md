# FR-001 — Вики объясняет назначение продукта

Serves: UC-001
Verified by: inspection

## Requirement

Читатель может установить по страницам продукта, для кого предназначен продукт, какую проблему он решает и какой результат обещает.

## Rationale

Это вопрос, с которым владелец пришёл к продуктовому репозиторию.
