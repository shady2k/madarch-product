# UC-005 — Заполнить граф продукта

Serves: US-003
Level: user goal
Primary actor: пользователь madarch
Scope: madarch

## Preconditions

Репозиторий продукта создан по UC-003 или UC-004.

## Success end condition

Каталог продукта записан в граф при старте сервера. Дальнейшее заполнение запускает пользователь. В граф попадают описания привязанных репозиториев кода, если они есть.

## Failed end condition

Заполнение невозможно, если сервер не запустился.

## Main success scenario

1. При старте сервера madarch проверяет манифесты и записывает каталог в граф без участия агента.
2. Пользователь запускает заполнение графа.
3. Если к продукту привязаны репозитории кода, в граф попадают их описания.

## Extensions

- 1a Манифесты не проходят проверку: сервер не запускается.
