# UC-001 — Узнать, что представляет собой продукт

Serves: US-001
Level: user goal
Primary actor: владелец продукта или новый участник команды
Scope: продуктовая вики madarch
Trigger: читатель открывает продуктовую вики

## Preconditions

Продуктовая вики доступна и содержит документы продукта.

## Success end condition

Читатель находит назначение продукта, для кого он создаётся, обещаемый результат и сведения о текущей вехе.

## Failed end condition

Читатель не может установить эти сведения по страницам вики.

## Main success scenario
1. Читатель открывает обзор продукта.
2. Читатель просматривает видение и аудиторию.
3. Читатель открывает текущую веху и её состояние.
4. Читатель видит, какие направления завершены, открыты или отложены.
