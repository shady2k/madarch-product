# UC-003 — Начать продукт с нуля

Serves: US-003
Level: user goal
Primary actor: пользователь madarch
Scope: madarch

## Preconditions

Кода продукта ещё нет.

## Success end condition

Создан только репозиторий продукта.

## Failed end condition

Репозиторий продукта не создан.

## Main success scenario

1. Пользователь запускает `madarch init` для продукта, у которого ещё нет кода.
2. Madarch создаёт репозиторий продукта.

Это один из двух режимов старта. При наличии кода применяется UC-004.
