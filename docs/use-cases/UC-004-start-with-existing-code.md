# UC-004 — Начать продукт с имеющимся кодом

Serves: US-003
Level: user goal
Primary actor: пользователь madarch
Scope: madarch

## Preconditions

Код продукта уже находится в репозитории.

## Success end condition

Создан репозиторий продукта, к которому привязан имеющийся репозиторий кода.

## Failed end condition

Репозиторий продукта не создан или репозиторий кода к нему не привязан.

## Main success scenario

1. Пользователь запускает `madarch init` в папке с имеющимся репозиторием кода.
2. Madarch создаёт репозиторий продукта.
3. Madarch привязывает имеющийся репозиторий кода к репозиторию продукта.

Для продукта, у которого ещё нет кода, применяется UC-003.
