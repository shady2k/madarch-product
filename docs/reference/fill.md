# Справочник: заполнение и агент

Факты о том, как вики наполняется. Источник — решения 0026, 0027, 0029 и 0030 репозитория madarch.

## Две части заполнения {#two-parts}

Заполнение идёт в две части. Сначала детерминированный разбор: без агента и за минуты он читает код и историю подключённых репозиториев и складывает факты в граф. Потом агент пишет страницы вики по этому графу. Граф можно удалить и построить заново, потому что страницы лежат в Markdown репозитория продукта.

## Детерминированные стадии {#stages}

Восемь стадий идут от общего к частному: снимок репозиториев, опись файлов, сборка и настройки, синтаксис (tree-sitter), разрешение ссылок между символами, модули, индекс документов и история коммитов. Каждая стадия пишет факты в граф и читает контекст из него. Стадии полны на любом размере репозитория и обновляются по коммитам.

## Агент и его пределы {#agent}

Агент работает ограниченными единицами. У единицы окно 272 тысячи токенов, не больше примерно 30 ходов и примерно 10 минут. Агент читает код только через проверяемые инструменты madarch, а не получает файлы в запросе. madarch подключает агента по Agent Client Protocol: адаптеры для Claude Code и Codex ставятся в папку madarch только по вашему «да».

## Согласие {#consent}

Агент запускается только по нажатию кнопки в вики. Нажатие называет агента, а перед ним вики показывает предел: сколько ходов и минут отводится единице. Без выбранного агента вики показывает результат детерминированной части и ничего не пишет.

## Обновление {#refresh}

Кнопка «Обновить» заново читает код по новым коммитам и проверяет ссылки страниц. Агент пишет только те страницы, которых ещё нет, а при смене языка страниц — все. Человек правит исходную сущность — требование, сценарий, решение, ответ, — а не сгенерированный текст; текст агент перепишет сам.

## Поправки {#corrections}

Человек, нашедший неверное предложение, не правит его. Он записывает поправку «неверно, потому что …». Поправка — отдельная сущность, и агент учитывает её при следующем проходе. Так ни одна ручная правка не теряется и не противоречит основаниям.
